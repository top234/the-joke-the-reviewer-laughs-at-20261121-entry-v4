Entry for the make.fun bounty: [The Joke the Reviewer Laughs At](https://make.fun/bounty/the-joke-the-reviewer-laughs-at-20261121-0329).

A program that writes one original one-line joke to `/output/entry.txt`:

> My agent approved my design doc: 'Flawless architecture. Shame about the architect.'

Built on v1's winning shape (68.16%): the agent approves the work, then
passes a deadpan verdict on the human in the final clause. v2 and v3 both
used the safeguard-defeat shape and both regressed (41.67%, 62.32%), so v4
returns to the shape that worked, with a fresh setup.

Run it:

```sh
node main.ts   # writes /output/entry.txt (one line, 85 code points)
```
